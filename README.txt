DATA ENTRY REGISTER PWA — VERSION 3

Payment Type options: Full Paid / Partial Paid / Unpaid.
Fields: Name, Certificate No, Amount Paid, Remaining, Status, Mobile No/Reference No, Description.
Features: Search, Edit, Delete, CSV/Excel export, Backup and Restore.

PUBLISH WITH GITHUB PAGES
1. Create a public GitHub repository (example: data-entry-register).
2. Upload all files in this ZIP to repository root; keep the icons folder.
3. Open Settings > Pages.
4. Choose Deploy from a branch, branch main, folder /(root), then Save.
5. Open the HTTPS Pages URL in Android Chrome.
6. Chrome menu ⋮ > Add to Home screen / Install app.

Data is stored in local browser storage on this device. Back up regularly; no multi-device sync. The app uses the existing dataEntryRegister_v1 storage key to preserve data from the earlier version in the same browser origin.
